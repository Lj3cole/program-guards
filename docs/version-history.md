# 程式守衛隊 · Code Guardians

以程式概念為角色的單人像素塔防。玩家花金幣隨機召喚基礎小兵、自由擺位、三合一升階，抵擋環形路線上的 Bug。第一版完成 20 波與兩隻頭目。

## 作業對應

- AGENTS.md 定義目的、風格、目錄、資料欄位、開發及擴充規則。
- 網頁依規則實作；角色、敵人、波次與系統設定分開存放。
- docs/extension-example.md 記錄依相同規則調整第 14 波的實際例子。
- GitHub Repository 連結：https://github.com/Lj3cole/program-guards
- GitHub Pages 網址：https://lj3cole.github.io/program-guards/

## 專案結構

網站檔案放在 dist/，其內部對應 AGENTS.md 的網站結構。dist/index.html 是網站入口。根目錄保留 AGENTS.md、README.md、tests/ 與擴充紀錄，發布時保留完整專案。

網站：dist/css/style.css、dist/js/main.js、dist/js/game.js、dist/js/render.js、dist/js/scene.js。
資料：dist/js/data/config.js、guards.js、enemies.js、waves.js、luck.js。
素材：dist/assets/units.png 是五欄四列圖集，前十九格依序存放三種小兵、八種守衛、六種小怪與兩隻頭目；最後一格留白。各資料項的 sprite 是零起算的圖集編號。透過 Canvas source rectangle 讀取，不需將角色逐張裁切。圖集為 AI 生成，保留使用者確認的角色概念；動態以位移、浮動及程式繪製攻擊效果呈現，尚非逐幀手繪走路動畫。

## 如何在電腦開啟

1. 將 ZIP 解壓縮，開啟專案資料夾。
2. 已安裝 Python 時，在該資料夾開啟終端機，執行 `python -m http.server 8000 --directory dist`。
3. 瀏覽器開啟 http://localhost:8000 。Windows 也可使用 `py` 取代 `python`。

本專案使用 JavaScript 模組，請透過 HTTP 伺服器開啟，不要直接雙擊 HTML。若使用 VS Code Live Server，開啟 dist/index.html 即可。

## GitHub Pages 發布

上傳完整專案至 GitHub。專案包含 .github/workflows/pages.yml，可在 Repository 的 Settings → Pages 將 Source 設為 GitHub Actions，讓工作流程發布 dist/。預設 main 分支，若使用其他分支需同步修改工作流程。啟用後將公開網址填回本 README。使用者已自行上傳 v0.3 並成功發布；本次 v0.5 請覆蓋更新後確認 Actions 成功。

## 操作

- 開始：第一波立即出怪，之後一般波最遲每 30 秒進波，全部敵人與排程清完即接下一波。
- 召喚：首次 20 金幣，每次成功後加 2，抽一隻守衛，自動上場，同款未滿三隻優先補位，否則另開空格。三階皆可抽：一階 75%、二階 20%、三階 5%，同階等機率，可連續召喚，再拖曳調整站位。
- 移動：拖曳同格整組角色，空格可移動、不同角色交換、相同角色總數最多三隻才可堆疊。
- 合成：點選同格三隻同款角色後按合成，隨機得到下一階角色。第二、三階各四種等機率；第三階不再合成。
- 角色數：最多 30 隻；三合一後減少兩隻。
- 空間：召喚前須確保所有可能結果都有去處；若沒有空格，召喚池全部十一種守衛必須各有未滿同種格，否則先整理位置。
- 暫停：戰鬥、操作與遊戲倒數均停止；離開分頁也會自動暫停，避免背景遊戲失控。
- 第 10、20 波只新增頭目，舊小怪保留。60 秒未擊敗頭目或存活怪物達 80 隻即失敗。
- 頭目期間停止下一波倒數，擊敗後若仍有小怪則恢復倒數，全部清空就直接進波。第 20 波頭目死亡且剩餘怪清空即勝利。
- 重新開始：清除本場狀態，回到開始畫面。

## 試玩初值

開局金幣 200、首次召喚 20（之後每次加 2）、小怪獎勵 3、頭目獎勵 100。普通怪基本血量乘上 `1.10 × 1.17^(波次-1)`。一般波依階段每波 32／34／36／38／40 隻，出怪間隔 0.55／0.52／0.50／0.48／0.46 秒。兩隻頭目血量 11000 與 34000。頭目擊退距離與暈眩時間為一般敵人的 0.25 倍。攻擊資料在 guards.js，各階能力均已實作。

if 對低於 30% 血量目標傷害加倍。function 每 4 秒範圍傷害；return 每 3 秒擊退；break（STOP）控制波冷卻 3.5 秒，有攻擊機會時暈眩目標周圍 115 範圍內敵人 1.4 秒（頭目 0.35 秒）；debug 每 3 秒範圍傷害。詳細數值由資料檔維護。

同一模擬步驟先結算擊殺、再檢查頭目到期；不同裝置以固定 1/60 秒的遊戲步驟推進，畫面停頓不補算無限時間。

## 測試

有 Node.js 時執行 `npm test`，不需安裝套件。

檢查召喚扣款、自動部署及連續召喚、角色上限、三合一、整組交換、堆疊、最高階限制、暫停、重新開始、頭目期限、80 隻失敗、最後清場與波次資料。

已用瀏覽器確認開始、召喚、放置、拖曳移動、堆疊合成、暫停與圖鑑；以三組固定隨機種子執行 20 波自動操作模擬（`node tests/simulate.mjs`）。這些不保證各種玩家策略均能過關，也不取代手機實機試玩。

## 來源與 AI 協助

玩法靈感來自《運氣拚輸贏》，本專案使用自己的名稱、角色、程式與數值，沒有使用原作程式或角色素材。

使用生成式 AI 協助需求討論、AGENTS.md、角色概念及圖集生成、程式實作與檢查。角色攻擊是程式概念的遊戲比喻，圖鑑另附實際詞彙說明。繳交時請附自己的需求 Prompt、生成結果及操作截圖。

## v0.3：運氣抽抽樂、遞增費用與像素地下基地

- 召喚：20、22、24……，每次成功召喚加 2。抽抽樂：100、150、200……，每次成功抽取加 50。兩者獨立，重新開始重設；失敗操作不扣款、不漲價。
- 五種增益：超頻模式 12%、火力更新 12%、系統緩速 10%、記憶體清理 10%、幸運援軍 6%。
- 五種負面：系統延遲 12%、火力異常 12%、Bug 加速 10%、意外入侵 10%、召喚干擾 6%。詳細數值及持續時間可在網頁展開「查看十種效果與目前機率」，或查 AGENTS.md 第 12 節。
- 援軍需保證各種二階結果都能放下，受角色總數上限限制；不符合時不參與抽選，其他機率按比例調整。抽到援軍後點亮起的格子放置，免費援軍不漲召喚價。
- 同種效果刷新時間、不疊加強度；不同效果倍率相乘。暫停會凍結效果與入侵排程，重新開始全部清空。
- 場景由原創低解析 Canvas 繪製，含石磚、牆柱、火燈、管線、終端機和箱子，經放大保持像素邊緣；不使用參考遊戲素材。
- `npm test` 共 24 項通過，涵蓋十種抽取及實際行為。瀏覽器確認抽獎與召喚扣款、價格遞增、結果、機率面板及新版場景。
- 平衡仍需試玩：舊固定擺位三組止於第 10 波；加入頭目追蹤擺位後三組止於第 19–20 波，20 組擴大觀察皆止於第 18–20 波。這些模擬沒有使用抽抽樂，不能當作玩家勝率或完整平衡證明。先保留已確認的費用與頭目規則，依實際試玩再討論。
- `node tests/simulate.mjs` 顯示三組自動操作的勝敗；正常戰敗是平衡觀察，並非程式崩潰。舊版 v0.2 通關紀錄不適用於新費用。

## v0.4：三階召喚與符號兵賞金

- 召喚一階 75%（各 25%）、二階 20%（各 5%）、三階 5%（各 1.25%）；費用仍從 20 開始，每次成功召喚加 2。高階不另外加價。

- 放置檢查擴大為十一種可能結果；無空格且任一結果無法放置時，不抽選、不扣款、不漲價。機率不因位置不足而偷偷調整。
- 波次、頭目、三合一與十種抽抽樂維持原設定；沒有降低 BOSS 血量或額外增加免費資源。
